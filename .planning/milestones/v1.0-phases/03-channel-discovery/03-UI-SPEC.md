## Spacing Scale

Declared values (multiples of 4, matching existing dashboard patterns):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), badge internal padding |
| sm | 8px | Inline element spacing (`gap-2`), filter label-to-input gap (`gap-1`) |
| md | 16px | Form element spacing (`gap-3`/`gap-4`), cell padding |
| lg | 24px | Section vertical rhythm (`space-y-6` = 24px) |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Touch targets for checkboxes: minimum 44px height per row (standard `TableRow` height already meets this via cell padding)
- Filter row: `flex flex-wrap gap-3 items-end` — 12px gap between filter controls, matching `videos-table.tsx` exactly

Source: Observed in `src/components/videos-table.tsx` and `src/components/outreach/enrich-form.tsx`

## Color

All values are dark-mode-first (dashboard forces `bg-gray-950` globally via layout).

| Role | Tailwind token | Raw value | Usage |
|------|---------------|-----------|-------|
| Dominant (60%) | `bg-gray-950` | `oklch(~0.06 0 0)` | Page background (`min-h-screen bg-gray-950`) |
| Secondary (30%) | `bg-gray-800` / `bg-gray-900` | `oklch(~0.21 0 0)` / `oklch(~0.15 0 0)` | Table container border, filter inputs, summary panel background |
| Accent (10%) | `text-white` / `border-white` / `text-blue-400` | varies | Active nav tab indicator, channel name links, selected-row outline |
| Destructive | `text-red-400` / `bg-destructive` | `oklch(0.704 0.191 22.216)` (dark) | Error messages, failed enrichment items only |

Accent reserved for:
1. Active tab border indicator in `DashboardNav` (`border-white text-white`)
2. Channel name anchor links (`text-blue-400 hover:underline`)
3. Checked checkbox and selected-row visual state
4. "Save X channels" primary CTA button (`bg-primary`, which is `oklch(0.922 0 0)` in dark mode — near-white)

Additional semantic colors (not accent):
- Success / enrichment complete: `text-green-400` — used only in the save-complete summary panel, matching Phase 2's `SummaryPanel` pattern
- Warning / partial save: `text-yellow-400` — partial rows in save summary
- Muted text: `text-gray-400` — filter labels, descriptions, empty state body
- Already-saved badge: `variant="secondary"` badge (gray) — visually distinct from enriched-data badges but not accent

Source: `src/app/dashboard/layout.tsx`, `src/components/dashboard-nav.tsx`, `src/components/videos-table.tsx`, `src/components/outreach/enrich-form.tsx`

## Interaction Contract

### Search Form

- Single `<Input>` (shadcn) + `<Button>` (shadcn) in a `flex gap-2` row — identical layout to `src/components/search-form.tsx`
- Submit: disabled when input is empty or loading; enabled as soon as one non-whitespace character is entered
- Loading: button text changes to "Searching…" with inline SVG spinner (`animate-spin h-4 w-4`), button disabled, input disabled — matching existing pattern verbatim
- On success: results table appears below the search row; search input stays populated (user may want to refine)
- On error: inline error paragraph below the form row (`text-red-400 text-sm`)

### Results Table

- Component: TanStack Table (`@tanstack/react-table`) — same library as `src/components/videos-table.tsx`
- Columns (left to right):
  1. Checkbox column — header: select-all checkbox; cell: individual checkbox (disabled + tooltip "Already saved" when `alreadySaved: true`)
  2. Channel name — plain text if not yet saved; anchor link (`text-blue-400 hover:underline`) pointing to `https://youtube.com/@handle` after save
  3. Subscribers — formatted with existing `fmt()` helper (K/M suffix); sortable; default sort ascending
  4. Top games — `—` (em-dash) until saved; comma-separated list after enrichment
  5. Genre — `—` until saved; badge (`variant="secondary"`) after enrichment
  6. Email — `—` until saved; rendered as `<a href="mailto:…">` when present; `—` when null after enrichment
  7. Status badge — see Status Badges table above

- Default sort: `subscriberCount ASC` (smallest first) — per CONTEXT.md D-08
- Sort indicators: ` ↑` / ` ↓` appended to header text — matching `videos-table.tsx` pattern
- Row hover: `hover:bg-gray-900` (same as videos table)
- Already-saved row: no hover highlight, slightly muted (`opacity-60` or `text-gray-500` treatment) — checkbox disabled
- Table container: `rounded-md border border-gray-800 overflow-hidden` — matching videos table

### Max-Subscribers Filter

- Position: above the table, left-aligned, in a `flex flex-wrap gap-3 items-end` row
- Control: `<Input type="number" className="w-32 bg-gray-800 border-gray-700 text-white">` with `<label className="text-xs text-gray-400">Max subscribers</label>`
- Default value: empty (no filter — show all channels)
- Filtering: client-side via `useMemo`, filters rows where `subscriberCount > maxSubs`
- Result count shown right-aligned in same row: `{N} channels found` in `text-gray-500 text-sm`

### Select-All Checkbox

- Header checkbox selects all visible (post-filter) rows that are NOT already saved
- Selection capped at 15: if visible unsaved rows > 15, select-all selects the first 15 in current sort order
- Over-limit guard fires when individual checkboxes are toggled past 15 (same client-side guard as Phase 2's `MAX_BATCH` check in `enrich-form.tsx`): inline message `Maximum 15 channels per save. Deselect some to continue.` appears below the Save button, Save button is disabled

### Save Flow

- Save button lives below the table, right-aligned
- State machine: idle → saving → complete (matches `enrich-form.tsx` pattern)
- During save: spinner + "Saving {N} channels…" text, button disabled, checkboxes disabled (prevent mid-save selection changes)
- In-place row update: as each channel enriches, its row cells (Top games, Genre, Email) update and the Status badge transitions from "Saving…" to "Saved" / "Partial" / "Failed" — no page reload, no table remount
- After save completes: inline `<SummaryPanel>` appears below the Save button (succeeded / partial / failed counts + expandable details list) — same structure as Phase 2's `SummaryPanel`
- Selected checkboxes cleared after successful save; already-saved badge applied to newly saved rows
