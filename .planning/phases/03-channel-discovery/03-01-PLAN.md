    // Email extraction (Phase 3 D-12).
    // Regex pre-chosen in CONTEXT.md: covers business addresses like

    // Returns null when the description has no parseable email.
    const EMAIL_RE = /[\w.+-]+@[\w-]+\.[a-z]{2,}/i;

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-01-04 | Elevation of Privilege | Migration applied without auth gate | mitigate | Migration is applied manually in the Supabase Dashboard by an authenticated project owner (Task 2 checkpoint). No app-level migration runner exists. |
| T-03-01-05 | XSS | enriched[url].genre / email rendered by Plan 03 without escaping | mitigate | React's default `{...}` interpolation escapes; `email` is rendered inside `mailto:` href which the browser treats as a URL — the same regex bounds the string to a safe alphabet (`[\w.+-]+@[\w-]+\.[a-z]{2,}`) ruling out script-injectable characters.
