## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact row cell padding, gap between inline buttons |
| md | 16px | Default element spacing, toolbar gap |
| lg | 24px | Section spacing inside tab panel (`space-y-6`) |
| xl | 32px | Top-of-page heading block |
| 2xl | 48px | Reserved — not used in this phase |
| 3xl | 64px | Reserved — not used in this phase |

Exceptions:
- Table row vertical padding: 8px (`py-2`) — intentionally compact, matches
  existing DiscoveryPanel rows.
- Filter inputs: fixed width 144px (`w-36`) for number inputs — matches
  DiscoveryPanel max-subscribers filter pattern.
- Touch targets on Re-enrich and Delete buttons: minimum 32px height — these
  are small inline action buttons in a dense table row.

Source: `discovery-table.tsx` class vocabulary.

## Color

All values from the `.dark` block in `globals.css` (OKLCH tokens).

| Role | CSS token | Approximate dark hex | Usage |
|------|-----------|----------------------|-------|
| Dominant (60%) | `--background` | #171717 | Page background, tab panel surface |
| Secondary (30%) | `--card` / `gray-900` | #1a1a1a / #111827 | Table container border, summary panel, filter row |
| Accent (10%) | `--primary` | #ebebeb | Active tab underline (`border-white`), primary button fill, channel name links |
| Destructive | `--destructive` | oklch(0.704 0.191 22.216) ≈ #f87171 | Delete button only |

Accent (`--primary` / `text-white` / `border-white`) is reserved for:
- Active tab indicator (bottom border of the selected tab button)
- Primary action button backgrounds (`<Button>` default variant)
- External link text that needs to stand out (`text-blue-400` — inherited pattern
  from existing channel-name links; do not introduce a new link colour)

Destructive colour is reserved for:
- The "Delete" per-row button (`variant="destructive"` or `text-red-400`)
- The "Delete selected" bulk-delete toolbar button when rows are checked

Muted foreground (`text-gray-400` / `text-gray-500`) is used for:
- Column headers
- Null/empty cell placeholders (em dash)
- Filter input labels
- Result-count chips in toolbar

Source: `globals.css` dark tokens, `discovery-table.tsx` class vocabulary.

## Layout: Outreach List Tab

The `OutreachTabs` component (`discovery-table.tsx` line 462) gains a third tab.
Tab bar order: `Discover channels | Bulk enrich | Outreach list`.

The Outreach list tab renders in a single `<div className="space-y-4">`:

```
[ Tab bar: Discover channels | Bulk enrich | Outreach list (active) ]

[ Toolbar row — flex, gap-3, items-center, flex-wrap ]
  [ Genre: <Select> ]   [ Min median views: <Input w-36> ]   [ Max subs: <Input w-36> ]
  [ {N} channel(s) — text-sm text-gray-400, ml-auto ]
  [ "Delete selected" <Button variant="destructive"> — only visible when selectedCount > 0 ]
  [ "Export CSV" <Button variant="outline"> with <Download> icon ]

[ Table container — rounded-md border border-gray-800 overflow-hidden ]
  [ TanStack Table ]
    Columns (left to right):
      checkbox | Channel name | Subscribers | Top games | Genre | Median views | Last enriched | Email | Actions
```

The Actions column is the rightmost column and contains two inline buttons
per row: Re-enrich and Delete. Both are small (`size="sm"`) with icon + text.

## Table Columns

| Column | Header label | Data source | Cell rendering |
|--------|-------------|-------------|----------------|
| Checkbox | — | TanStack `RowSelectionState` | `<input type="checkbox">`, disabled during any re-enrich in progress on that row |
| Channel name | Channel name | `outreach_channels.name` | `<a href={url} target="_blank" className="text-blue-400 hover:underline">` |
| Subscribers | Subscribers | `outreach_channels.subscriber_count` | `fmt(n)` or `<span className="text-gray-500">—</span>` if null |
| Top games | Top games | `outreach_channels.top_games` (array) | `top_games.join(', ')` in `text-sm text-gray-200`, or `—` if null/empty |
| Genre | Genre | `outreach_channels.genre` | `<Badge variant="secondary">{genre}</Badge>` or `—` if null |
| Median views | Median views | `outreach_channels.median_views` | `fmt(n)` or `—` if null |
| Last enriched | Last enriched | `outreach_channels.last_enriched_at` | `new Date(ts).toLocaleDateString()` (browser locale, short date), or `—` if null |
| Email | Email | `outreach_channels.email` | `<a href="mailto:{email}" className="text-blue-400 hover:underline font-mono text-xs">` or `—` if null |
| Actions | — | — | Re-enrich button + Delete button, `size="sm"`, `gap-2` |

Default sort: `last_enriched_at desc` (most recently enriched first). Columns
sortable by TanStack: Channel name (string), Subscribers (numeric), Median views

## Interaction States

### Re-enrich (per-row, CONTEXT.md D-03)

1. **Idle:** Row shows Re-enrich button with `<RefreshCw>` icon, label "Re-enrich".
2. **Loading:** Row fades to `opacity-50`. Button shows `<Loader2 className="animate-spin">` icon, label "Enriching…", disabled. Delete button on that row is also disabled.
3. **Complete (success):** Row snaps to updated field values (top_games, genre, median_views, subscriber_count, email, last_enriched_at). Opacity returns to 100. Button returns to idle state.
4. **Complete (partial):** Same as success snap, but a `<Badge variant="outline" className="text-yellow-400">Partial</Badge>` replaces the Re-enrich button label momentarily (1 frame, then returns to idle). Partial means LLM call failed — data was saved with null top_games/genre.
5. **Complete (failed):** Row opacity returns to 100. Re-enrich button label briefly shows "Failed" in `text-red-400` then returns to idle. No row data changes.

Mechanism: `setRows(prev => prev.map(r => r.youtubeId === target ? {...r, enriching: true} : r))` pattern, matching `DiscoveryPanel.handleSave()` in `discovery-table.tsx`.

### Delete (per-row, CONTEXT.md D-04)

Immediate optimistic removal. Row is removed from local state before the API
call completes. No confirmation dialog. No undo.

If the API DELETE call fails (network error): restore the row to local state
and show an inline `text-red-400 text-sm` error message in the toolbar:
"Delete failed — please try again."

### Bulk Delete (CONTEXT.md D-05)

1. Checkboxes appear in leftmost column (same as DiscoveryPanel pattern).
2. Header checkbox selects / deselects all visible (filtered) rows.
3. When `selectedCount > 0`, "Delete selected" button appears in toolbar
   (`variant="destructive"`, label: "Delete {N} channel{N===1?'':'s'}").
4. On click: optimistic removal of all selected rows. Single API call with
   all selected `youtube_id` values. If bulk call fails, restore removed rows
   and show toolbar error.
5. Row selection resets to empty after bulk delete completes (success or fail).

### Export CSV (CONTEXT.md D-06, D-07, D-08)

Pure client-side. No API call.

On click of "Export CSV":
1. Collect filtered rows from TanStack table's current row model.
2. Build CSV string: UTF-8, comma-separated, header row first.
3. Column order: `Channel name,URL,Subscribers,Top games,Genre,Median views,Last enriched,Email`
4. Array fields (`top_games`): joined with ` | ` separator (pipe-separated within the CSV cell, quoted to avoid comma conflicts).
5. Null fields: empty string in CSV (no em dash).
6. Trigger download: `Blob(['...'], {type: 'text/csv;charset=utf-8'})` + `URL.createObjectURL` + `<a>.click()`.
7. Filename: `outreach-channels-{YYYY-MM-DD}.csv` (today's date, client timezone).

### Filter Behaviour (CONTEXT.md D-09 through D-12)

All filtering is `useMemo` client-side, recalculated on each filter change.

| Filter | Input type | Behaviour |
|--------|-----------|-----------|
| Genre | `<Select>` dropdown | Options: "All genres" + distinct genre values from loaded rows. Rows with null genre pass when "All genres" selected; excluded when a specific genre is selected. |
| Min median views | `<Input type="number" placeholder="e.g. 5000">` w-36 | Rows with null median_views are excluded when a value is set. No value = no filter. |
| Max subscribers | `<Input type="number" placeholder="e.g. 100000">` w-36 | Rows with null subscriber_count pass the filter (matches DiscoveryPanel pattern, CONTEXT.md D-11). No value = no filter. |

Filter inputs use classes: `bg-gray-900 border-gray-700 text-white placeholder:text-gray-500` — matching existing filter inputs in `DiscoveryPanel`.

## Empty & Loading States

| State | Trigger | Visual |
|-------|---------|--------|
| Loading | Tab first mounts, fetching rows from Supabase | Single `<TableRow>` spanning all columns: `<Loader2 className="animate-spin h-5 w-5 text-gray-400 mx-auto">` with `py-12` row padding. No text. |
| Empty (no channels) | Fetch completes with 0 rows | Centred in table: heading "No outreach channels yet", body "Save channels from the Discover tab to populate this list.", `py-12 text-center` |
| Empty (filters active) | Rows exist but all filtered out | Centred in table: "No channels match the current filters." with hint "Try clearing the genre filter or adjusting the view/subscriber thresholds.", `py-8 text-center text-gray-400 text-sm` |
| Load error | Supabase fetch throws | Toolbar-level `<p className="text-red-400 text-sm">`: "Failed to load outreach channels — please refresh the page." |
